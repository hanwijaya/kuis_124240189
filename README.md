# Daftar Mobil

Aplikasi Flutter untuk soal kuis SI-B.

- Login: username bebas (tidak kosong), password `124240189`.
- Beranda: sapaan username dan daftar 10 mobil dari data dummy `car.dart`.
- Detail: merek, nama, gambar, deskripsi, harga rupiah, dan tahun.
- Profil: username, teks pernyataan sesuai soal, avatar hijau, pilihan warna biru/merah/ungu, serta logout.
- Navigasi Beranda dan Profil menggunakan BottomNavigationBar.

Jalankan dengan `flutter run`. Gambar dari data dummy membutuhkan internet.

Validasi: `flutter analyze` dan `flutter test`.

Sesuai format pengumpulan pada soal, nama repositori GitHub adalah `kuis-124240189`.
